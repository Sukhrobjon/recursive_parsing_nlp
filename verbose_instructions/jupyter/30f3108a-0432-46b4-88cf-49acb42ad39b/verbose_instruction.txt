8) Type the hyper-parameter search loop that evaluates K from 1 to 30 using 5-fold cross-validation inside a Pipeline (scaler + KNN):  
```python
k_range   = range(1, 31)
cv_scores = []

for k in k_range:
    knn_pipe = Pipeline(
        steps=[
            ("scaler", StandardScaler()),
            ("knn",    KNeighborsRegressor(n_neighbors=k))
        ]
    )
    # Negative MAE so higher is better; we invert later
    mae_scores = cross_val_score(
        knn_pipe,
        X_train,
        y_train,
        cv=5,
        scoring="neg_mean_absolute_error",
        n_jobs=-1
    )
    cv_scores.append(-mae_scores.mean())   # store positive MAE

best_k       = k_range[int(np.argmin(cv_scores))]
best_mae     = min(cv_scores)

print(f"Best k: {best_k}  |  CV Mean Absolute Error: {best_mae:.4f}")
```
