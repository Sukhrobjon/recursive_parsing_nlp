```python
import sqlite3, pandas as pd

# Connect to the local SQLite database
connection = sqlite3.connect('database.db')

query = """
SELECT
    actor.actor_id,
    actor.first_name,
    actor.last_name,
    COUNT(rental.rental_id)            AS rented_times
FROM actor
LEFT JOIN film_actor ON actor.actor_id = film_actor.actor_id
LEFT JOIN film       ON film_actor.film_id = film.film_id
LEFT JOIN inventory  ON film.film_id      = inventory.film_id
LEFT JOIN rental     ON inventory.inventory_id = rental.inventory_id
GROUP BY actor.actor_id
ORDER BY rented_times DESC
LIMIT 10;
"""

# Run the SQL, load into a DataFrame, and export to CSV
df = pd.read_sql_query(query, connection)
df.to_csv('result.csv', index=False)
connection.close()
```

Note that we JOIN the five relevant tables, aggregate with COUNT(rental_id), then sort by rented_times in descending order and LIMIT to 10 actors. This directly answers the task requirement.
