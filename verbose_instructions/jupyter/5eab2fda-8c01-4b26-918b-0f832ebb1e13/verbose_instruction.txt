9. Paste the loading, aggregation, and export code into this new cell:  
```python
import pandas as pd

# Load CSV into a DataFrame
df = pd.read_csv('usa_baby_names.csv')

# Bulk-insert into SQLite
df.to_sql('baby_names', conn, if_exists='append', index=False)
conn.commit()

# SQL query: names that appear in every distinct year
query = """
SELECT
    first_name,
    SUM(num) AS total_num
FROM
    baby_names
GROUP BY
    first_name
HAVING
    COUNT(DISTINCT year) = (SELECT COUNT(DISTINCT year) FROM baby_names)
ORDER BY
    total_num DESC;
"""

result = pd.read_sql_query(query, conn)

# Persist the answer for grading
result.to_csv('result.csv', index=False)

# Optional sanity check
print(result.head(), f"\nTotal qualifying names: {len(result)}")
```
