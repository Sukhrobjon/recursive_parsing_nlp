1. Log in to Snowsight, wait until the worksheet loads, then confirm we are in the correct role and warehouse by typing and executing:  
   ```sql
   USE ROLE ACCOUNTADMIN;
   USE WAREHOUSE COMPUTE_WH;
   ```
   (This guarantees we have permission to create filters and run queries.)

2. Click the funnel-shaped “Filters” button (icon with two horizontal lines) in the very top-left corner of the worksheet toolbar.

3. Click “Manage Filters” in the drop-down list that appears.

4. In the “Manage Filters” dialog, click the blue “+ Filter” button in the upper-right corner.

5. Type Title_Keyword into the “Display Name” input field.

6. Type :title_keyword (Snowsight automatically adds the colon; just type title_keyword) into the “SQL Keyword” input field—this will be referenced later inside the query.

7. In the “Warehouse” drop-down, choose COMPUTE_WH so the filter’s query always runs on that warehouse.

8. Click the blue “Write Query” button that appears below the form; a query editor pops up.

9. In the left database selector of the pop-up, click DB > PUBLIC to set the default database and schema for the filter.

10. Paste the following SQL into the filter’s query editor:  
    ```sql
    SELECT DISTINCT job_title
    FROM salary;
    ```
    This returns every unique job title in the SALARY table; we will later choose “Data Analyst” from this list.

11. Click the ▶︎ Run button at the upper-right of the pop-up; verify a grid of job titles appears in the result panel.

12. Click the “Done” button in the upper-left of the query pop-up to return to the main filter dialog.

13. Click the blue “Save” button in the lower-right corner of the “Manage Filters” dialog, then click “Done” to close it. Our custom filter is now available in the worksheet toolbar.

14. Press Ctrl+Shift+N (or click the “+ Worksheet” tab) to open a brand-new SQL worksheet.

15. Copy the contents of query.txt from your desktop (you can open the file with a text editor) and paste it into the blank worksheet. The pasted code should read:  
    ```sql
    SELECT AVG(salary) AS average_salary
    FROM salary
    WHERE job_title = :title_keyword;
    ```

16. Click the “Title_Keyword” pill-shaped button that now appears just above the query editor (next to the warehouse selector).

17. In the drop-down list populated from our earlier filter query, choose “Data Analyst” (it should be the second option). The button now displays Data Analyst, indicating the bind variable :title_keyword has that value.

18. Click the “No database selected” area to the left of the worksheet toolbar, choose DB → PUBLIC, and then click the blue “Apply” button immediately to the right of the “Title_Keyword” button. This pins the database context for the query.

19. Click the ▶︎ Run button in the upper-right of the worksheet to execute the query. We expect a single row with column average_salary.

20. Confirm that the results grid shows exactly one row and a numeric value under average_salary; this verifies the filter worked.

21. Hover over the results pane and click the downward-arrow “Download Results” icon in its upper-right corner.

22. Select “Download as .csv” in the drop-down; Snowsight immediately saves a file (e.g., results_20240318_123456.csv) to your browser’s default download directory.

23. Switch to your terminal (or file manager) and navigate to the download folder:  
    ```bash
    cd ~/Downloads
    ```

24. Rename the file to result.csv (replace the autogenerated filename):  
    ```bash
    mv results_*.csv result.csv
    ```

25. List the directory to confirm the rename succeeded:  
    ```bash
    ls -l result.csv
    ```
    The file should appear with the exact name result.csv and a recent timestamp, confirming completion of the task.
