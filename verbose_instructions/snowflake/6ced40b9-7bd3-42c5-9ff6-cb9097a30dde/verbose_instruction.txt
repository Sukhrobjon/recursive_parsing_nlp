1. Open the Snowsight web browser tab that is already authenticated to your Snowflake account (the tab where you can see worksheets).  
2. Click the left-hand vertical navigation icon labeled “Activity.”  
3. Click the submenu item “Query History.” The main panel now shows the Query History grid.  
4. Confirm the page header reads “Query History” so we know we are on the correct page.  
5. Click the “Time Range” drop-down near the upper-right corner of the grid (default is often “24 hours”).  
6. Select “Custom…” at the bottom of the list. A calendar pop-up appears.  
7. In the “Start Date” picker, click the date that is exactly 3 days earlier than today (e.g., if today is April 10, pick April 7).  
8. Leave the “End Date” set to today’s date; click the blue “Apply” button. We have now restricted the grid to the last three days.  
9. Click the “Status” filter pill (it shows “All” by default) located directly above the grid headers.  
10. Select only the “Failed” checkbox and uncheck all others; click “Apply.”  
11. Click the “User” filter pill next to it; ensure “All Users” is selected so we capture queries from every user.  
12. Verify the grid refreshes and the “Status” column for every row displays a red “FAILED” badge.  
13. Scroll through a few rows and check the “Start Time” column—each timestamp should fall within the last three calendar days.  
14. (Optional) Click the small funnel icon on the rightmost side of the grid header to save this filter view as “Failed_Last3Days” for future use.  
15. We have now successfully displayed all failed queries for all users in the last 3 days.
