3. In the Explorer, click tests/test_dag.py to open the unit-test skeleton.  
4. Write the import test at the top of the file:

```python
# tests/test_dag.py
from airflow.models import DagBag

def test_dag_loaded():
    """
    DAG import should succeed and exactly one DAG called
    'example_pipeline' must be present.
    """
    dagbag = DagBag(include_examples=False)
    assert len(dagbag.import_errors) == 0, f"Import errors: {dagbag.import_errors}"
    assert 'example_pipeline' in dagbag.dags
```

5. Add a function that checks the number of tasks:

```python
def test_task_count():
    dag = DagBag(include_examples=False).dags['example_pipeline']
    assert len(dag.tasks) == 3, "DAG must contain exactly 3 tasks"
```

6. Insert a function to verify every expected task_id exists:

```python
def test_task_ids_present():
    dag = DagBag(include_examples=False).dags['example_pipeline']
    expected = {"start", "middle", "end"}
    found = {t.task_id for t in dag.tasks}
    assert expected == found, f"Missing tasks: {expected - found}"
```

7. Create a function to validate dependencies:

```python
def test_dependencies():
    dag = DagBag(include_examples=False).dags['example_pipeline']
    upstream = dag.get_task('middle').upstream_task_ids
    downstream = dag.get_task('middle').downstream_task_ids
    assert upstream == {'start'}
    assert downstream == {'end'}
```
