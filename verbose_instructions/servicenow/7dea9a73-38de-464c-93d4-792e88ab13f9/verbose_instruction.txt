1. Navigate to https://console.cloud.google.com/bigquery so the BigQuery Web UI opens in a new browser tab.  
2. Look at the left-hand Resources panel and locate your project name (for example, my-project-123).  
3. Click the triangle ▶ to the left of the project name to expand all datasets inside it.  
4. Click the triangle ▶ next to the dataset that contains the “catalog_items” table (for example, `ecommerce_ds`) so every table in that dataset is displayed.  
5. Click the table name `catalog_items`; the right-side panel switches to the Schema tab where we can verify the three columns we need: `created_by`, `flow`, and `classic_mobile_picture_type`—this confirms the exact column spellings we will reference in SQL.  
6. Click the + Compose new query button (blue, near the top of the BigQuery window). A new blank query editor appears in the central pane.  
7. Write the SQL query that sorts by the required columns in descending order:  
```sql
SELECT
  *
FROM
  `my-project-123.ecommerce_ds.catalog_items`
ORDER BY
  created_by               DESC,
  flow                     DESC,
  classic_mobile_picture_type DESC;
```  
   • Note that every ORDER BY field ends with DESC so the list is sorted from highest → lowest (or Z → A) for each column, exactly as requested.  
8. Click the ➤ Run button (big blue “Run” at the top-right of the query editor). The Query results panel appears beneath the editor after a few seconds.  
9. Confirm in the results grid that rows are ordered first by Created by, then within each Created by value by Flow, and finally by Classic Mobile Picture Type. We can scroll a few pages to visually verify the sort sequence.  
10. If you need to preserve this sorted list, click Save Results (on the right side of the Query results title bar) and choose CSV (local file) or Google Sheets as desired. Follow your browser prompts to download or open the file.  
11. Optionally click the ✎ Save button on the query editor’s toolbar, choose “Save query”, enter a name like “Sort catalog_items by created_by_flow_picturetype”, and click Save so the query is stored in your history for future reuse.
