   • Produce a list of files,  
   • Calculate the size of each file in bytes,

6) Write the import block that pulls Dagster primitives. Type the following in file_sizes_job.py:  
```python
from pathlib import Path
from typing import List, Tuple

from dagster import op, Out, In, job, get_dagster_logger
```

7) Create the first op to list every file in the current directory. Under the import block, type:  
```python
@op(out=Out(List[Path]))
def list_files() -> List[Path]:
    """Return a list of Path objects for every file in the current folder (non-recursive)."""
    logger = get_dagster_logger()
    files = [p for p in Path(".").iterdir() if p.is_file()]
    logger.info(f"Found {len(files)} files")
    return files
```

8) Add the second op that maps files to (name, size_in_bytes) tuples:  
```python
@op(ins={"files": In(List[Path])}, out=Out(List[Tuple[str, int]]))
def get_file_sizes(files: List[Path]) -> List[Tuple[str, int]]:
    """Return (filename, size) tuples for every Path in the input list."""
    result = [(p.name, p.stat().st_size) for p in files]
    get_dagster_logger().info(f"Computed size for {len(result)} files")
    return result
```

9) Create the third op to filter out small files (< 1024 bytes):  
```python
@op(ins={"file_sizes": In(List[Tuple[str, int]])}, out=Out(List[Tuple[str, int]]))
def filter_large_files(file_sizes: List[Tuple[str, int]]) -> List[Tuple[str, int]]:
    """Keep only files whose size is >= 1 KB."""
    filtered = [t for t in file_sizes if t[1] >= 1024]
    get_dagster_logger().info(f"{len(filtered)} files are >= 1 KB")
    return filtered
```

10) Define the fourth op that aggregates the total size and logs a human-readable report:  
```python
@op(ins={"large_files": In(List[Tuple[str, int]])})
def summarize_sizes(large_files: List[Tuple[str, int]]):
    """Log a report of all large files and their cumulative size."""
    total_bytes = sum(s for _, s in large_files)
    logger = get_dagster_logger()
    logger.info("==== File Size Report (>=1 KB) ====")
    for name, size in large_files:
        logger.info(f"{name.ljust(30)} {size:>10} bytes")
    logger.info("-" * 45)
    logger.info(f"TOTAL: {total_bytes} bytes across {len(large_files)} files")
```

11) Create the Dagster job wiring the four ops. Append:  
```python
@job
def file_sizes_job():
    summary = summarize_sizes(filter_large_files(get_file_sizes(list_files())))
    return summary
```
