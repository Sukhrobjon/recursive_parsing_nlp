1. Navigate to https://console.cloud.google.com/bigquery so the BigQuery Web UI opens in your browser.  
2. Click the small triangle ▶ to the left of bigquery-public-data in the left-hand Explorer panel so its list of public datasets expands.  
3. Scroll down and click the triangle ▶ next to thelook_ecommerce to reveal its tables; then click products to inspect its schema in the main pane (we can see columns such as id, name, category, created_at, retail_price—created_at gives us the product year, which we will use shortly).  
4. Click the blue + Compose new query button (or the + icon just above the schema) to open a blank SQL editor tab.  
5. Write the following SQL into the editor to find 2019 products whose retail_price is strictly above the 2019 average price:  

```sql
-- 2019 products whose price is above the 2019 average price
WITH year_products AS (
  SELECT
    id,
    name,
    category,
    retail_price,
    EXTRACT(YEAR FROM created_at) AS yr
  FROM
    `bigquery-public-data.thelook_ecommerce.products`
  WHERE
    EXTRACT(YEAR FROM created_at) = 2019      -- keep only 2019 products
),
avg_price AS (
  SELECT
    AVG(retail_price) AS avg_retail_price_2019
  FROM
    year_products
)
SELECT
  p.id,
  p.name,
  p.category,
  p.retail_price
FROM
  year_products AS p
CROSS JOIN
  avg_price AS a
WHERE
  p.retail_price > a.avg_retail_price_2019     -- above-average filter
ORDER BY
  p.retail_price DESC;
```  

6. Click the green ► Run button located above the query editor to execute the SQL.  
7. Wait a few seconds; the Query results pane appears at the bottom with all matching 2019 products. Quickly glance at the row count to confirm data returned (we will export these rows next).  
8. Click the Save results button (just above the results grid, right side) and choose CSV (local file) from the dropdown.  
9. In the file-save dialog that your browser opens, navigate to your Downloads folder, type result.csv as the filename, and click Save (or OK).  
10. Confirm the file result.csv now exists in ~/Downloads; you can open it to verify the list contains only 2019 products priced above the 2019 average.
