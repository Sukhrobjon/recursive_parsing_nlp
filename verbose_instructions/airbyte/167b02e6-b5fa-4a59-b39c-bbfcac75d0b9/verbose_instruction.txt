1) Open the macOS Finder so we can see where the Desktop folder is located (~/Desktop) – we will copy the database there shortly.  
2) Switch to the Terminal app (⌘ + Space → type “Terminal” → press Return).  
3) Type the command below to move into the Airbyte workspace directory created by the Docker compose bundle (it is where Airbyte keeps all generated files):  
```bash
cd ~/airbyte_workspace
```  
   Note that if your Airbyte project lives somewhere else, replace the path accordingly (e.g. `~/airbyte`).

4) Execute a quick search for any SQLite files produced by Airbyte; we limit the depth to five sub-directories so the scan finishes quickly:  
```bash
find . -maxdepth 5 -type f -name "*.db" -o -name "*.sqlite"
```  
   • Observe the paths returned – one of them will be the file generated by the “SQLite” destination.  
   • Typical matches look like `./data/destination_sqlite/database_ab1234567890.sqlite`.

5) Copy the full relative path of the file that clearly belongs to your Airbyte connection (it is usually the most recent file or the only one in `destination_sqlite`).  
   For example, assume the command in Step 4 returned:  
   `./data/destination_sqlite/my_airbyte_connection.sqlite`

6) Verify the file really contains your tables by inspecting its schema with the `sqlite3` CLI:  
```bash
sqlite3 ./data/destination_sqlite/my_airbyte_connection.sqlite ".tables"
```  
   • If you see the expected table names, you’ve located the correct database.  
   • Type `.exit` and press Return to leave the sqlite prompt.

7) Copy the verified file to the Desktop and rename it to epidemiology.sqlite in a single command:  
```bash
cp ./data/destination_sqlite/my_airbyte_connection.sqlite ~/Desktop/epidemiology.sqlite
```

8) Confirm that the copy succeeded:  
```bash
ls -lh ~/Desktop/epidemiology.sqlite
```  
   • The output should show a file size greater than 0 bytes.  
   • If the file is listed, the task is complete.

9) (Optional) Double-click `epidemiology.sqlite` in Finder → Desktop to open it with DB Browser for SQLite or another viewer and ensure the tables are browsable.
