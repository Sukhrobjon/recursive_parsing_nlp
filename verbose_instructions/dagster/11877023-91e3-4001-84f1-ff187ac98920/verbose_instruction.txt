1. Switch to VS Code. In the left Explorer, expand the folder “iris_classification/assets”, then click the file “__init__.py” to open it in the editor.  
2. Scroll to the bottom of “__init__.py” and type the following new asset definition. The code filters the existing `iris_dataset` Pandas DataFrame and writes the result to a DuckDB table named `iris_virginica`.  
```python
# assets/__init__.py

@asset(
    name="iris_virginica",
    group_name="classification",
    io_manager_key="duckdb_io_manager",   # ← make sure your DuckDB I/O manager is already configured
    compute_kind="python",
)
def iris_virginica(iris_dataset: pd.DataFrame) -> pd.DataFrame:
    """
    Filter Iris-virginica rows and persist them to DuckDB table `iris_virginica`.
    """
    virginica_df = iris_dataset[iris_dataset["species"] == "Iris-virginica"].reset_index(drop=True)
    # Dagster will automatically write `virginica_df` to DuckDB via the I/O manager
    return virginica_df
```
3. Press Ctrl+S to save the file.  
4. Confirm the project’s `dagster.yaml` (located at the repo root) already has the DuckDB I/O manager registered. Quickly open it and verify you have something like:  
```yaml
resources:
  duckdb_io_manager:
    config:
      database: "warehouse/iris.duckdb"
```
   If it’s missing, add the snippet, save, and close the file.  
5. Switch to the terminal (integrated VS Code terminal or external). From the project root, run:  
```bash
dagster dev
```  
   Wait until the local Dagster UI reports “Launched Dagit at http://127.0.0.1:3000”.  
6. Go to your web browser and open “http://127.0.0.1:3000”.  
7. In Dagit, look at the left sidebar and click “Assets”. Then click the “classification” asset group.  
8. Click the button “Reload definitions” (top-right) so the newly added `iris_virginica` node appears in the lineage graph just downstream of `iris_dataset`.  
9. Click the green “Materialize all” button. In the pop-up, verify that both “iris_dataset” and “iris_virginica” are selected, then click “Materialize”.  
10. Wait for the run page to show the status “Succeeded” (all steps should turn green).  
11. Expand the step “iris_virginica” in the run logs and confirm the log line that shows the output table path similar to `warehouse/iris.duckdb:iris_virginica`.  
12. Switch back to the terminal and open a DuckDB shell to verify the data was written:  
```bash
duckdb warehouse/iris.duckdb
```  
13. At the DuckDB prompt, run the query:  
```sql
SELECT DISTINCT species, COUNT(*) AS rows
FROM iris_virginica
GROUP BY species;
```  
   You should see exactly one row with `species = 'Iris-virginica'` and the row count (usually 50).  
14. Type `.quit` to exit DuckDB. The asset `iris_virginica` is now fully implemented, materialized, and verified.
