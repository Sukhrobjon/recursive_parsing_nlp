1. Click the New button in the top-right corner of the Metabase window.  
2. Select Question from the drop-down menu that appears.  
3. Click the Pick your starting data panel, then expand Sample Database and choose Orders.  
4. Click the Summarize sidebar on the right.  
5. Under Pick the metric you want to see, click the drop-down, choose Sum of, then select Subtotal.  
6. Click the Pick a column to group by drop-down and choose Created At → Year.  
7. Click the blue + button that appears just below the first grouping pill.  
8. Choose Product → Category from the list to add the second grouping.  
9. Click the + button again and select User → State to add the third grouping.  
10. Click the Visualize button in the top-right corner.  
11. In the visualization type panel, click Pivot Table (it has a grid icon).  
12. Wait a moment until the pivot table renders; we can see Sum of Subtotal values arranged by Year, Category, and State.  
13. Click the Download full results button in the bottom-right corner of the page (down-arrow icon).  
14. In the download modal, click the .xlsx option.  
15. Wait until the browser finishes downloading the file; by default it will land in /home/user/Downloads with a name like Orders-2024-06-<timestamp>.xlsx (exact timestamp varies).  
16. Switch to the terminal application.  
17. Run the following command to confirm the download name:  
    ```bash
    ls /home/user/Downloads | grep .xlsx
    ```  
18. Execute a rename so the file is exactly query_result.xlsx:  
    ```bash
    mv /home/user/Downloads/Orders-*.xlsx /home/user/Downloads/query_result.xlsx
    ```  
19. Copy the renamed file to the desired location:  
    ```bash
    cp /home/user/Downloads/query_result.xlsx /home/user/query_result.xlsx
    ```  
20. Open the workbook with the default spreadsheet viewer:  
    ```bash
    libreoffice /home/user/query_result.xlsx &
    ```  
21. In LibreOffice Calc, click any cell in the Sum of Subtotal column of the pivot table.  
22. Click Data in the top menu bar, then select Sort.  
23. In the Sort dialog, set Sort Key 1 to Sum of Subtotal and choose Ascending.  
24. Click OK and verify the pivot table now lists rows from the smallest to largest Sum of Subtotal.  
25. Save the workbook by pressing Ctrl+S, confirm the filename remains /home/user/query_result.xlsx, and close the spreadsheet viewer.
