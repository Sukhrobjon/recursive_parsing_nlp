1. Click the triangle ▶ to the left of dataset name patents-public-data in the left “Explorer” pane, then click the nested dataset patents to expand it.  
2. Click publications to highlight the table; we can see its schema in the right “Table details” panel (note the columns—application_number and country_code are the ones we will use).  
3. Click + Compose new query in the top-right of the main panel to open a new blank SQL editor tab.  
4. Write the aggregation query below into the editor pane:  
```sql
SELECT
  country_code
FROM (
  SELECT
    ANY_VALUE(country_code) AS country_code
  FROM
    `patents-public-data.patents.publications` AS pubs
  GROUP BY
    application_number            -- ensures one row per patent application
)
GROUP BY
  country_code
ORDER BY
  COUNT(*) DESC                   -- sort by number of patents
LIMIT 10;                         -- keep only the top 10
```  
5. Click ► Run (blue RUN button) in the toolbar of the query tab to execute the SQL.  
6. Wait until the message “Query complete” appears and the results grid shows exactly 10 rows containing only country_code values.  
7. Click SAVE RESULTS located above the results grid, then choose CSV (local file) from the dropdown.  
8. Wait for the browser download dialog; confirm the file downloads to the default location (~/Downloads on most systems). Remember the autogenerated name (e.g., results-2024-05-14T12_34_56.csv).  
9. Switch to the terminal application.  
10. Type cd ~/Downloads and press Enter to move into the Downloads directory.  
11. Execute ls to list files; locate the newly downloaded CSV file name.  
12. Run the rename command, replacing <auto-name>.csv with the real file name you saw in step 11:  
```bash
mv <auto-name>.csv result.csv
```  
13. Execute ls again and verify result.csv now appears in the directory—this confirms the file was renamed successfully and contains your top-10 country list.
