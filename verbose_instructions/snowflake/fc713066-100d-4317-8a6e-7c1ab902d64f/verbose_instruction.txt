5) Replace the default comments in cell [1] with the following Python code, copying the table schema from schema.txt (assume three example columns; overwrite with the real list you saw in step 1):

```python
# code cell 1  – create DB, schema, stage, file format, and table, then load data
from snowflake.snowpark import Session
from snowflake.snowpark.types import StructType,StructField,IntegerType,StringType

# 1. create a Snowpark session using the current worksheet context
session = Session.builder.getOrCreate()

# 2. choose names for DB and schema
db_name = "COUNTRY_DB"
schema_name = "PUBLIC_COUNTRY"

session.sql(f"CREATE DATABASE IF NOT EXISTS {db_name}").collect()
session.sql(f"USE DATABASE {db_name}").collect()
session.sql(f"CREATE SCHEMA IF NOT EXISTS {schema_name}").collect()
session.sql(f"USE SCHEMA {schema_name}").collect()

# 3. create stage that points to the provided S3 bucket
session.sql("""
CREATE OR REPLACE STAGE country_stage
URL='s3://sfquickstarts/tastybytes/raw_pos/country/'
FILE_FORMAT=(FORMAT_NAME='country_csv_fmt')
""").collect()

# 4. create a CSV file-format object (no header)
session.sql("""
CREATE OR REPLACE FILE FORMAT country_csv_fmt
TYPE=CSV
FIELD_DELIMITER=','
SKIP_HEADER=0
""").collect()

# 5. create table using schema from schema.txt
country_schema = StructType([
    StructField("country_id", IntegerType()),
    StructField("country_name", StringType()),
    StructField("country_code", StringType())
])
session.table("INFORMATION_SCHEMA.TABLES")  # dummy line to keep cell valid

session.sql("""
CREATE OR REPLACE TABLE country (
    country_id   INTEGER,
    country_name STRING,
    country_code STRING
)
""").collect()

# 6. load data from the stage
session.sql("""
COPY INTO country
FROM @country_stage
FILE_FORMAT = (FORMAT_NAME='country_csv_fmt')
ON_ERROR='ABORT_STATEMENT'
""").collect()
```

6) Click the blue “Run” ▶ button at the top of the worksheet to execute cell 1; confirm you see `SUCCESS` in the Results pane for each DDL/COPY command.
