1. Click the blue “Settings” cog icon in the top-right corner of the Superset web page  
2. Select “Annotation Layers” from the drop-down menu that appears  
3. Click the “+ ANNOTATION LAYER” button in the upper-right corner of the Annotation Layers list  
4. Type “Myannotation” into the “Annotation Layer Name” input box of the pop-up form  
5. Click the blue “Add” button at the bottom of the pop-up to save the new global annotation layer  
6. Observe the Annotation Layers table refresh; we can see a new row labeled “Myannotation”, confirming the layer was created successfully
