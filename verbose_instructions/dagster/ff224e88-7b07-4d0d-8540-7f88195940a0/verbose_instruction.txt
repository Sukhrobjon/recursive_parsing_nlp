   Note that every downstream asset will therefore look for a resource named “parquet”; we will register that shortly.

4. Click parquet_io_manager.py in the Explorer to open it.  
5. Scroll to the ParquetIOManager class and place the cursor inside the existing handle_output method body.  
6. Type (or paste) the exact implementation below, replacing any existing pass statement:

```python
    def handle_output(self, context: OutputContext, obj: pd.DataFrame):
        # Persist a DataFrame to a parquet file
        path = self._get_path(context)

        # Create folders only for local file-system paths
        if "://" not in self._base_path:
            os.makedirs(os.path.dirname(path), exist_ok=True)

        if isinstance(obj, pd.DataFrame):
            row_count = len(obj)
            context.log.info(f"Row count: {row_count}")
            obj.to_parquet(path=path, index=False)
        else:
            raise Exception(f"Outputs of type {type(obj)} not supported.")

        # Surface useful metadata in Dagster UI
        context.add_output_metadata({"row_count": row_count, "path": path})
```
