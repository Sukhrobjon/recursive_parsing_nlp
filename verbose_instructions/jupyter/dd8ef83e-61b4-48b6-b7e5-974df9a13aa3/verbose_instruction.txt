6. Type the following code block exactly; it reads the CSVs and loads them into an in-memory SQLite database:  
```python
import pandas as pd
import sqlite3

# read the raw CSV files
film_actor     = pd.read_csv('./film_actor.csv')
film_category  = pd.read_csv('./film_category.csv')
film           = pd.read_csv('./film.csv')
category       = pd.read_csv('./category.csv')

# create / connect to a temporary SQLite database
connection = sqlite3.connect('database.db')

# load each DataFrame into SQLite (replace if the table already exists)
film_actor.to_sql('film_actor', connection, if_exists='replace', index=False)
film_category.to_sql('film_category', connection, if_exists='replace', index=False)
film.to_sql('film', connection, if_exists='replace', index=False)
category.to_sql('category', connection, if_exists='replace', index=False)
```  
Note that we load all four CSV files even though only category and film_category are strictly required; having the others available keeps the database consistent for future queries.  
7. Hover below this new cell and click  Click to add a cell  again.  
8. Paste the SQL aggregation query and export logic below:  
```python
query = """
SELECT
    c.name,
    COUNT(fc.film_id) AS films_in_category
FROM
    category AS c
    LEFT JOIN film_category AS fc
        ON c.category_id = fc.category_id
GROUP BY
    c.category_id
ORDER BY
    films_in_category DESC;
"""

df = pd.read_sql_query(query, connection)

# write the final output to result.csv
df.to_csv('result.csv', index=False)

# display the DataFrame so we can visually confirm
df
```  
We use LEFT JOIN to ensure categories with zero films still appear; the ORDER BY clause sorts by the count in descending order.
