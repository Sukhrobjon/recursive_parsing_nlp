1. Open the Snowflake Web UI in your browser and sign in with your normal credentials.  
2. Click the “+  Worksheet” button in the upper-right corner to create a fresh SQL worksheet; a new tab labelled “Worksheet …” opens.  
3. Type the role-selection command exactly as shown below, then hit the blue ► Run button in the upper-right corner of the worksheet:  
```sql
USE ROLE analyst;
```  
(We assume the analyst role has read access to IMDB. If you normally use a different role, substitute it here.)  
4. Select the warehouse that will execute the query. Still in the same worksheet, paste and run:  
```sql
USE WAREHOUSE compute_wh;
```  
5. Switch the context to the IMDB database and its default schema:  
```sql
USE DATABASE imdb;
USE SCHEMA public;
```  
6. Quickly review the requirements.txt file so we match every rule (it asked for Drama genre, year ≥ 2000, sorted by rating, pick top 20 rows).  
7. Write the final SQL query that filters, orders, and limits the data. Replace the existing blank line in the worksheet with:  
```sql
/* Top 20 Dramatic movies since 2000 (inclusive) */
SELECT
       title_id,
       primary_title            AS title,
       start_year               AS release_year,
       average_rating,
       num_votes,
       genres
FROM   imdb.public.titles
WHERE  genres ILIKE '%Drama%'
  AND  start_year >= 2000
  AND  title_type = 'movie'
ORDER BY average_rating DESC,
         num_votes     DESC
LIMIT 20;
```  
8. Click the ► Run button again. Wait until the Results pane (bottom half) returns exactly 20 rows.  
   • If you see fewer rows, double-check the filter conditions.  
   • If you see 20 rows, the query meets the requirement—good job!  
9. Verify the columns appear in the order Title_ID, Title, Release_Year, Average_Rating, Num_Votes, Genres; this matches what we need for the CSV.  
10. In the bottom Results pane, click the small download icon (looks like a downward arrow with a line) located in the upper-right corner of that pane.  
11. From the dropdown, choose “Download as CSV”. A file named similar to “Result_ … .csv” will be generated by the browser.  
12. When your browser’s Save dialog appears, navigate to “Desktop”, rename the file to exactly top20movies.csv, and click “Save”.  
13. Open the saved top20movies.csv on your desktop with a spreadsheet editor or a text editor to confirm it contains 20 lines of data plus a header row; verify the first header cell is TITLE_ID and the last one is GENRES.  
14. Celebrate—your top-20 dramatic movies list since 2000 is now on your desktop in top20movies.csv and ready to share!
