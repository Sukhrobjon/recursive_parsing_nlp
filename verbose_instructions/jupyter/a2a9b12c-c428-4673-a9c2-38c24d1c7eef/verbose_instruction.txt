1. Locate the “File Browser” (left-hand sidebar with the folder icon) and click the triangle beside “Desktop” to expand its contents.  
2. Double-click “code.py” so it opens in the built-in text viewer tab on the right.  
3. Press Ctrl + A to highlight the entire script, then press Ctrl + C to copy it to the clipboard.  
4. Switch back to the File Browser panel, click the “+” (New Launcher) button in the top-left corner, and in the launcher choose “Python 3 (ipykernel)” under the “Notebook” section; a new untitled notebook tab appears.  
5. Click the notebook title “Untitled.ipynb” at the top, type tensor.ipynb, and press Enter to rename it.  
6. Click once inside the first (only) empty code cell so you see the blue border.  
7. Press Ctrl + V to paste the entire contents of code.py into this cell; verify that every line from the original file now appears in this single cell.  
8. Choose File ➜ Save Notebook (or press Ctrl + S) so tensor.ipynb is written to disk with the copied code.  
9. Confirm success by glancing at the tab title—there should be no “*” next to tensor.ipynb, indicating it has been saved, and the cell should display the full script without needing to run it.
